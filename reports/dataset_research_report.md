# CDS 525 数据集研究报告

## 概述

本报告对课程项目可选的6个数据集进行详细分析，包括数据分布、预测/分类方向、难度评估和模型推荐。

---

## 1. Fake News Detection (假新闻检测)

### 1.1 数据集概况

| 属性 | 值 |
|-----|-----|
| 样本数量 | 4,729 |
| 任务类型 | 二分类 |
| 数据类型 | 文本 (英文) |
| 标签 | Real / Fake |
| 文件格式 | CSV |
| 许可证 | CC0 Public Domain |

### 1.2 预测方向

- **目标**: 根据新闻文本内容判断其真实性
- **输入**: 新闻标题/正文文本
- **输出**: Real (真实) 或 Fake (虚假)

### 1.3 技术挑战

1. **文本长度变化大**: 新闻长度从几十词到上千词不等
2. **语义理解**: 需要理解新闻的逻辑和事实一致性
3. **领域知识**: 某些假新闻需要背景知识才能识别

### 1.4 推荐模型

| 模型 | 优势 | 预期准确率 |
|-----|-----|----------|
| BERT | 强大的语义理解能力 | 90-95% |
| DistilBERT | 速度快，性能接近BERT | 88-93% |
| RoBERTa | 更好的预训练策略 | 91-96% |
| LSTM + Attention | 轻量级，训练快 | 85-90% |

### 1.5 难度评估: ⭐⭐ (中等)

## 2. Financial News Sentiment (金融新闻情感分析)

### 2.1 数据集概况

| 属性 | 值 |
|-----|-----|
| 样本数量 | ~4,840 |
| 任务类型 | 三分类 |
| 数据类型 | 文本 (英文) |
| 标签 | Negative / Neutral / Positive |
| 来源 | FinancialPhraseBank |
| 许可证 | CC BY-NC-SA 4.0 |

### 2.2 数据分布特点

根据原始论文，标签分布通常为:
- **Neutral**: ~59% (多数类)
- **Positive**: ~28%
- **Negative**: ~13% (少数类)

**注意**: 数据集存在类别不平衡问题

### 2.3 预测方向

- **目标**: 分析金融新闻标题的情感倾向
- **输入**: 金融新闻标题 (通常较短)
- **输出**: 情感类别 (正面/中性/负面)

### 2.4 技术挑战

1. **类别不平衡**: Negative类别样本较少
2. **领域特定词汇**: 金融术语需要特殊处理
3. **隐含情感**: 金融新闻情感表达较为含蓄

### 2.5 推荐模型

| 模型 | 优势 | 预期准确率 |
|-----|-----|----------|
| FinBERT | 金融领域预训练 | 85-90% |
| BERT | 通用语义理解 | 82-88% |
| XLNet | 处理长依赖关系 | 83-89% |

### 2.6 难度评估: ⭐⭐ (中等)

## 3. Social Media Sentiment (社交媒体情感分析)

### 3.1 数据集概况

| 属性 | 值 |
|-----|-----|
| 任务类型 | 多分类 |
| 数据类型 | 文本 |
| 来源 | 社交媒体帖子 |
| 许可证 | MIT |
| 文件大小 | ~14KB |

### 3.2 预测方向

- **目标**: 识别社交媒体文本中的情感
- **输入**: 社交媒体帖子文本
- **输出**: 情感类别

### 3.3 技术挑战

1. **非正式语言**: 包含缩写、表情符号、俚语
2. **噪声数据**: 拼写错误、语法不规范
3. **短文本**: 上下文信息有限

### 3.4 推荐模型

| 模型 | 优势 | 适用性 |
|-----|-----|-------|
| BERTweet | 专门针对Twitter数据预训练 | 最佳 |
| RoBERTa | 鲁棒性强 | 优秀 |
| BERT | 通用性好 | 良好 |

### 3.5 难度评估: ⭐⭐ (中等)

## 4. Harmful Brain Activity Classification (有害脑活动分类)

### 4.1 数据集概况

| 属性 | 值 |
|-----|-----|
| 任务类型 | 多分类 |
| 数据类型 | 时间序列 (EEG脑电图) |
| 来源 | HMS Kaggle竞赛 |
| 数据格式 | Parquet / CSV |

### 4.2 分类类别

根据竞赛描述，需要识别的有害脑活动包括:
- Seizure (癫痫发作)
- LPD (Lateralized Periodic Discharges)
- GPD (Generalized Periodic Discharges)
- LRDA (Lateralized Rhythmic Delta Activity)
- GRDA (Generalized Rhythmic Delta Activity)
- Other (其他)

### 4.3 预测方向

- **目标**: 从EEG信号中识别有害脑活动模式
- **输入**: 多通道EEG时间序列数据
- **输出**: 脑活动类别

### 4.4 技术挑战

1. **高维时序数据**: 多通道、长时间序列
2. **专业领域知识**: 需要理解EEG信号特征
3. **数据预处理复杂**: 需要滤波、标准化等
4. **类别不平衡**: 某些脑活动模式较少见

### 4.5 推荐模型

| 模型 | 优势 | 适用性 |
|-----|-----|-------|
| 1D CNN | 捕捉局部时序模式 | 良好 |
| LSTM/GRU | 处理长时间依赖 | 良好 |
| Transformer | 全局注意力机制 | 优秀 |
| EfficientNet + Spectrogram | 转为图像分类 | 优秀 |

### 4.6 难度评估: ⭐⭐⭐ (较难)

## 5. KMNIST (日文手写字符识别)

### 5.1 数据集概况

| 属性 | 值 |
|-----|-----|
| 样本数量 | 70,000 |
| 训练集 | 60,000 (每类6,000) |
| 测试集 | 10,000 (每类1,000) |
| 图像尺寸 | 28 x 28 灰度图 |
| 类别数 | 10 |
| 数据格式 | MNIST格式 / NumPy |

### 5.2 类别说明

10个类别对应日语平假名的10行:
- お (o), き (ki), す (su), つ (tsu), な (na)
- は (ha), ま (ma), や (ya), れ (re), を (wo)

### 5.3 数据分布

**完美平衡**: 每个类别样本数量相同
- 训练: 6,000/类
- 测试: 1,000/类

### 5.4 预测方向

- **目标**: 识别手写日文字符
- **输入**: 28x28灰度图像
- **输出**: 10个平假名类别之一

### 5.5 技术挑战

1. **字符相似性**: 某些平假名形状相近
2. **书写风格变化**: 古代书法风格多样
3. **笔画复杂度**: 比MNIST数字更复杂

### 5.6 推荐模型

| 模型 | 参数量 | 预期准确率 |
|-----|-------|----------|
| LeNet-5 | ~60K | 95-97% |
| ResNet-18 | ~11M | 98-99% |
| VGG-11 | ~9M | 97-98% |
| EfficientNet-B0 | ~5M | 98-99% |

### 5.7 难度评估: ⭐ (简单)

## 6. CIFAR-100 (图像分类)

### 6.1 数据集概况

| 属性 | 值 |
|-----|-----|
| 样本数量 | 60,000 |
| 训练集 | 50,000 (每类500) |
| 测试集 | 10,000 (每类100) |
| 图像尺寸 | 32 x 32 RGB |
| 细分类别 | 100 |
| 超类数量 | 20 |

### 6.2 超类结构示例

| 超类 | 包含的细分类别 |
|-----|--------------|
| aquatic mammals | beaver, dolphin, otter, seal, whale |
| flowers | orchid, poppy, rose, sunflower, tulip |
| vehicles 1 | bicycle, bus, motorcycle, pickup truck, train |
| reptiles | crocodile, dinosaur, lizard, snake, turtle |

### 6.3 数据分布

**完美平衡**:
- 每个细分类别: 500训练 + 100测试
- 每个超类: 2,500训练 + 500测试

### 6.4 预测方向

- **目标**: 识别图像中的物体类别
- **输入**: 32x32 RGB图像
- **输出**: 100个类别之一 (或20个超类之一)

### 6.5 技术挑战

1. **细粒度分类**: 100个类别区分度要求高
2. **低分辨率**: 32x32图像信息有限
3. **类内变化大**: 同类物体外观差异大
4. **类间相似**: 某些类别视觉特征相近

### 6.6 推荐模型

| 模型 | 参数量 | 预期准确率 |
|-----|-------|----------|
| ResNet-56 | ~0.85M | 72-75% |
| WideResNet-28-10 | ~36M | 80-82% |
| DenseNet-BC | ~25M | 78-82% |
| Vision Transformer | ~86M | 85-90% |
| EfficientNet-B0 | ~5M | 78-82% |

### 6.7 难度评估: ⭐⭐ (中等)

## 选题建议
